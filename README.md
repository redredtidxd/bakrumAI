# bakrumAI

Juego de terror procedural estilo Backrooms en el navegador (Three.js).

- **Mundo infinito** generado por chunks con semilla determinista: pasillos, salas, salones y zonas vacías se mezclan en campos de ruido suave.
- **Oscuridad por zonas**: apagones totales donde solo alumbra la linterna (tecla F), zonas tenues y normales.
- **Estructuras repetidas limitadas**: hileras de salas idénticas (máx. 3 copias).
- **El monstruo** te persigue: el contacto directo con línea de visión te mata; el flash de la cámara lo aturde.
- Muebles con física, tiza para marcar el camino, notas de lore y objetos recogibles.

## Archivos

- `index.html` — entrada del juego (usa `js/`)
- `backrooms-single-file.html` — versión autocontenida en un solo archivo

## Cómo jugar

Abre `index.html` (o `backrooms-single-file.html`) en un navegador moderno.
